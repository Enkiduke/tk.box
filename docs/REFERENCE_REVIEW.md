# Read-only reference review — October 17, 2026

Reviewed architecture, dependency manifests, root license texts and the relevant implementation paths below from the supplied local snapshots. No reference tree was edited, installed, duplicated, merged or included in tk.box's build. Version fields describe the snapshots, not a claim about current upstream releases.

| Reference | Architecture and inspected implementations | License and tk.box decision |
| --- | --- | --- |

The new runtime dependencies are deliberate: Fastify/cookie/rate-limit (MIT), better-sqlite3 (MIT, native prebuilt installation exercised), Zod (MIT), saxes (ISC), React/ReactDOM (MIT), hls.js (Apache-2.0). TypeScript (Apache-2.0), tsx/Vite and their build dependencies are development tooling. Exact resolved versions are pinned by `package-lock.json`; upstream notices remain in their packages. Public build assets use explicit file routes, without directory listing or a wildcard filesystem handler. FFmpeg is an externally installed executable, not redistributed here; its actual build/license options must be reviewed for any eventual distribution. Do not infer a combined application license from private prototype use.
